基本設定

Microsoft 365 クラウド同期

在庫データを御社のMicrosoft 365（SharePoint）に保存し、パソコン・スマホ・社外のすべての端末で同じ在庫を共有します。従業員は会社のMicrosoftアカウントでサインインします。データは御社テナントの外には出ません。

状態: 確認中…

部品リストは既存の「部品マスター」に接続します（無ければ自動作成。在庫数・発注点の列は自動追加され、Power Apps側はそのまま動きます）。履歴リストと「車両在庫」リストは自動作成されます。写真もSharePointのライブラリに保存され、全端末で同期されます（初回は写真が多いと時間がかかります）。同時編集は後から保存した内容が優先されます。端末の時刻は「自動設定」を推奨します。

初回セットアップ手順（管理者・約15分）
  1. このファイルをNetlifyに置いてHTTPSのURLを発行（無料）。
  2. Entra管理センター →「アプリ登録」→「新規登録」。名前は任意（例：部品在庫管理）、「サポートするアカウントの種類」は「この組織ディレクトリのみのアカウント」。
  3. 「認証」→「プラットフォームを追加」→「シングルページアプリケーション(SPA)」→ リダイレクトURIに手順1のURLを入力 →「構成」。
  4. 「APIのアクセス許可」→「アクセス許可の追加」→「Microsoft Graph」→「デリゲートされたアクセス許可」→ User.Read / Sites.ReadWrite.All / Sites.Manage.All を追加 →「…に管理者の同意を与えます」をクリック。
  5. 「概要」の「アプリケーション（クライアント）ID」をコピー → 上の欄に貼り付けて「保存」。
  6. 「Microsoftでサインイン」→ 会社アカウントで承認 →「接続」→ 既存の「部品マスター」リストに接続（無ければ作成。在庫数・発注点の列は自動追加）→ 初回同期（データが多いと1〜2分）。
  7. 他の端末（スマホ等）は同じURLを開いてサインインするだけで在庫が表示されます。

※ アプリ登録が制限されているテナントでは、IT管理者に手順2〜5を依頼してください。

データのバックアップ

データはこのブラウザ内に保存されます。USBメモリや社内共有フォルダに保管する場合は、バックアップファイル（JSON）を出力してください。別のPCへは「バックアップ出力 → 復元」で移行できます。

Excelで集計・加工する場合はCSV出力をご利用ください。

スマホで使う（QRコード）

このページをスマホで開くためのQRコードを表示します。HTTPSのURLで開いている場合は、AndroidのChromeで開き、メニュー「⋮」→「ホーム画面に追加」でインストールできます。

部品写真の一括取込

写真ファイル名を部品コード（型式・部品番号）にして選択すると、自動で対応する部品に登録されます。例）6233113340.jpg

写真はこのブラウザ内（IndexedDB）に保存され、クラウド同期設定時はSharePointにも保存されます。JSONバックアップには含まれないため、元の写真ファイルは別途保管してください。

データの初期化

このソフトについて

  • 部品の登録・検索、入庫・出庫・棚卸調整・現場受け取りの記録、倉庫と営業車（出張倉庫）の間の移動、発注点管理ができます。営業車は出張倉庫として扱い、移動では払出金額は発生しません。
  • バーコード：部品マスタの「ラベル印刷」でCode128ラベルを出力し、USBスキャナやカメラで読み取って入出庫できます（カメラ読取はChrome／Edge対応）。
  • 写真：部品編集で1部品につき複数枚の写真を登録できます（一覧・入出庫時に表示）。設定の「部品写真の一括取込」なら、ファイル名を部品コードにして一括登録できます。
  • 在庫数の修正は「入出庫」の棚卸調整を使うと、履歴として残ります。
  • 棚卸モード：棚の順に実地数量を入力すると未入力がひと目で分かり、確定時に差異が「棚卸調整」としてまとめて記録されます（差異CSV出力付き）。
  • スマートフォン・タブレットでも操作できます（画面下のメニューから移動）。
  • Microsoft 365同期：設定の「Microsoft 365 クラウド同期」でサインインすると、SharePointリスト経由で全端末が同じ在庫を共有できます（社外からの確認も可能。写真も同期されます）。
  • 毎月の棚卸時にバックアップ（JSON）やCSVを出力して保管することを推奨します。
